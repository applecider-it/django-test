# Djangoモノリス



## 機能

- 認証
- ツイート
- 管理画面

## 追加要素

- Vite (管理クラスは自作)
- Typescript
- Vue
- Tailwind

## 構造

```
account/ <- アプリケーション
app/ <- 共通コード
assets/ <- Vite管理ファイル
home/ <- アプリケーション
main/ <- アプリケーション
myproject/ <- 主に設定
static/ <- 静的ファイル
templates/ <- 共通テンプレート
tweet/ <- アプリケーション
```

## 評価

上記の構造を見ればわかる通り、レイヤーが混ざりやすい。

管理画面はすぐできるけど、activeadminと同じで、ブラックボックスのため難しくなってくる。

実装例では使わなかったけど、クラスベースビュウが、ブラックボックス。

このデザインパターンは、ぱっと見は、コードが減るけど、運用していくと、難しくなってくるため、実装例では、あえて、利用していない。

アプリケーション分割も、一長一短。

分割できるメリットと、見通しが悪くなるデメリットが両方ある。

Viteを使う場合は工夫が必要。
